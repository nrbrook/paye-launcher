PAYE Launcher
=============

PAYE Launcher opens HMRC Basic PAYE Tools on a Mac when the HMRC app does not
open (for example after a macOS update).

1. Install Basic PAYE Tools from GOV.UK first:
   https://www.gov.uk/basic-paye-tools

2. Drag "PAYE Launcher" to the Applications folder.

3. Open PAYE Launcher from the Applications folder. Basic PAYE Tools opens in
   its own window. Your data stays where Basic PAYE Tools keeps it
   (the HMRC folder in your home folder).

4. To close, quit PAYE Launcher (PAYE Launcher menu > Quit). It makes the same
   automatic backup as Basic PAYE Tools.

PAYE Launcher is free software (GNU GPL version 3). It is not made by, connected
with or endorsed by HMRC. It contains no HMRC software.

Help and source code: https://github.com/nrbrook/paye-launcher
